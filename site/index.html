Get open modelsmodels from their sources, verified.

A command-line tool that downloads open model weights and checks every file against the hash its source publishes, or the one you pin.

curl -fsSL https://lmget.org/install.sh | sh

Windows, in PowerShell: irm https://lmget.org/install.ps1 | iex

0models mirrored
0verified by sha256
0mirror nodes
0signed nicknames
0until the signature expires

Use

A name in, a verified model where your tools look.

lmget qwen
A nickname: lmget reads this machine's memory and the apps installed, proposes the Qwen3.5 variant that fits, and asks before downloading.
lmget Qwen/Qwen3-0.6B
Downloads, verifies and links into the Hugging Face cache.
lmget info Qwen/Qwen3-0.6B
Shows the plan and downloads no weights.
lmget mlx-community/Qwen3.5-0.8B-4bit --to omlx
Links into oMLX. --to lmstudio, --to jan, --to localai, --to exo, --to colibri and --to comfyui link into those apps.
lmget ollama:smollm2:135m
Lands in Ollama, ready for ollama run.

A real run

Every file checked against the hash its source publishes.

The output of --plain, set in columns, with each sha256 shortened (point at one to see it whole; narrow screens leave them out). Each is the one Hugging Face publishes for that file at that commit.

What it does

From Hugging Face (ModelScope as a second origin), the Ollama registry, OCI registries and https URLs.

  • Every file verified

    Checked against the hash its source publishes, or the one you pin.

  • No hidden pickle

    Pickle content under another name is refused; pickle weights are skipped when safetensors exist.

  • Stored once

    Parallel, resumable downloads, each file stored once by sha256.

  • Where your tools look

    Linked into the Hugging Face cache, Ollama, oMLX, LM Studio, Jan, LocalAI, exo, colibri, ComfyUI or a directory.

  • Nicknames

    qwen, whisper or embed pick the variant that fits the machine; the list is signed like the index.

  • When the source fails

    A signed index and mirror nodes keep the models it lists available, even to a first run.

Nicknames

One name, the variant that fits: lmget picks it and asks before downloading.

The signed nickname list maps names such as qwen to the variants of a model family.

Mirrored models

Served by the project's nodes when the source fails, every file listed with its sha256.

The signed index lists the models the project mirrors and the nodes that serve them. lmget verifies its minisign signature before using it.

Install

macOS, Linux and Windows, amd64 and arm64.

The script checks the archive against the release's checksums and, when gh is installed and signed in, its build provenance, then installs into ~/.local/bin. Or take an archive from the latest release (v0.5.0, 2026-11-19).
