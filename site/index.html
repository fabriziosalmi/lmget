Get open models from their sources, verified.

  • Checks every file against the hash its source publishes, and refuses pickle content hidden under another name.
  • Resumes parallel downloads, stores each file once by sha256, and links the model where your tools already look.
  • When a source fails, a signed index and mirror nodes keep indexed models available.
lmget Qwen/Qwen3-0.6B        # download, verify, link
lmget info Qwen/Qwen3-0.6B   # the plan only
lmget ollama:smollm2:135m    # ready for ollama run

Sources: Hugging Face (with ModelScope as a second origin), the Ollama registry, OCI registries and https URLs.

Install

Download the archive for macOS or Linux from the latest release, then check where it was built:

gh attestation verify lmget_*.tar.gz --repo fabriziosalmi/lmget \
  --signer-workflow fabriziosalmi/lmget/.github/workflows/release.yml
