Get open models from their sources, verified.

A command-line tool that downloads open model weights and checks every file against the hash its source publishes, or the one you pin.

curl -fsSL https://lmget.org/install.sh | sh

Windows, in PowerShell: irm https://lmget.org/install.ps1 | iex

Install

For macOS and Linux, amd64 and arm64; Windows with the PowerShell script above. The script checks the archive against the release's checksums and, when gh is installed and signed in, its build provenance, then installs into ~/.local/bin. Or take an archive from the latest release (v0.3.2, 2026-11-18).

Use

lmget qwen
lmget Qwen/Qwen3-0.6B
lmget info Qwen/Qwen3-0.6B
lmget mlx-community/Qwen3.5-0.8B-4bit --to omlx
lmget ollama:smollm2:135m

qwen is a nickname: lmget reads this machine's memory and the apps installed, proposes the Qwen3.5 variant that fits, and asks before downloading. The second downloads, verifies and links into the Hugging Face cache. info shows the plan and downloads nothing. --to omlx, --to lmstudio, --to jan, --to localai and --to exo link into those apps; the last lands in Ollama, ready for ollama run.

What it does

  • Checks every file against the hash its source publishes, or the one you pin, and refuses pickle content hidden under another name.
  • Resumes parallel downloads, stores each file once by sha256, and links the model where your tools already look: the Hugging Face cache, Ollama, oMLX, LM Studio, Jan, LocalAI, exo or a directory.
  • Nicknames such as qwen, whisper or embed pick the variant that fits the machine; the list is signed like the index.
  • When Hugging Face fails, a signed index and mirror nodes keep the models it lists available, even to a first run.
  • Sources: Hugging Face (with ModelScope as a second origin), the Ollama registry, OCI registries and https URLs.

Works with

  • The Hugging Face cache (the default): transformers, sentence-transformers, llama.cpp -hf, Goose's local inference, Lemonade.
  • Ollama: Ollama, RamaLama's ollama:// models, and the apps that ask Ollama for a model, such as Open WebUI, Page Assist, Hollama and Oterm.
  • Their own folders: oMLX, LM Studio, Jan, LocalAI, exo.
  • A plain directory: Text Generation WebUI, and apps given a file path, such as KoboldCpp, llamafile and llama-server.
  • Through a server: chat and agent apps that keep no model files of their own (LobeChat, LibreChat, Cherry Studio, Chatbox, SillyTavern, Dify, Langflow) use the models of the local server they ask, which lmget fills.

Read from each project's source or documentation on 2026-11-18. The folders and layouts are in the README.

Nicknames

The signed nickname list maps names such as qwen to the variants of a model family; lmget picks the one that fits the machine and asks before downloading.

Mirrored models

The signed index lists the models the project mirrors, with every file's sha256 and the nodes that serve them. lmget verifies its minisign signature before using it.
